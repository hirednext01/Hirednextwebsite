# HiredNext candidate email standard

Taru requested this standard on 14 September 2026 for the email body and all future candidate correspondence.

- Body font: `Aptos, 'Segoe UI', 'Helvetica Neue', Arial, sans-serif`, 16px, line-height 1.7. Use the available fallback on the recipient's device; do not load remote web fonts.
- HiredNext navy: `#0c3466`. Orange accent: `#ff4e16`. Main reading text: `#172033`. White content background; muted outer background `#f4f6f9`.
- Keep headings navy and use orange sparingly for the brand accent. Use short paragraphs, 18px paragraph spacing and a 640px maximum content width with comfortable mobile padding.
- Send HTML with inline styles and a plain-text alternative. Use the shared `App\Services\HiredNextEmail` renderer for website mail. Existing subjects, recipients, threads, prices, attachments and delivery controls stay with their service owner.
- For personal Gmail replies, apply the same font, size, spacing and navy/orange signature in the HTML body. Keep correspondence concise; a short reply needs only a compact branded signature, not a large campaign header.
- Use **HiredNext Recruitment** as the brand. No unrelated colour themes, script fonts, image-only body copy, tracking pixels or claims of personal founder review.
- Never resend a previous candidate message merely to update its appearance.

An internal style preview is sent once to jobs with reference `HN-EMAIL-STYLE-1`. It is not an enquiry, order or sale.
